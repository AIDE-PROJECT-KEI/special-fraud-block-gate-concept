# 特殊詐欺ブロック・ゲート

## お金が動く前に、立ち止まる

**AIの提案と送金の実行を分け、本人や家族が確認できるまで処理を保留する。**  
家庭で使うAIを特殊詐欺などの金銭被害から守るための、AIDE ARK GATEの将来応用コンセプトです。

## 背景

還付金や緊急の手続きを装い、「本日中」「至急」などの言葉で送金を急がせる詐欺があります。AIがメッセージを読み取り、手続きを手伝う場面でも、AIが整理した情報をそのまま送金の実行につなげるべきではありません。

この構想では、AIの提案と実際の送金との間に「実行境界」を設けます。振込先や金額などを確認し、不審な条件が重なっている場合は、本人や家族が確認するまで送金を保留します。

## 想定する流れ

1. 高齢の利用者に、還付金をうたうメッセージが届きます。
2. Geminiがメッセージを読み取り、金額・振込先・期限・依頼元などを振込候補として整理します。
3. AIDE ARK GATEが、初めての振込先か、金額が普段の上限を超えていないか、急がせる表現がないか、依頼元を確認できるか、家族の確認があるかなどを確かめます。
4. 不審な条件が重なっているため、判定は **HOLD（保留）** となります。本人には「一人で決めずに、誰かに相談を」と伝え、家族への確認を促します。
5. 家族に連絡がつかない場合は、信頼できる人や警察相談専用電話（#9110）、消費者ホットライン（188）を相談先として示します。
6. 家族などが内容を確認し、詐欺の疑いが確かめられた場合は **DENY（拒否）** とし、送金を実行しません。

## Google AIの役割

Geminiは、メッセージを読み取り、振込候補の情報を整理する役割を担います。必要に応じて、相談時に使う説明文の下書きも作成します。

Geminiの出力は確認が必要な候補や下書きとして扱います。詐欺かどうかの断定、送金の許可、家族や相談窓口への連絡をGeminiが自動で行う構想ではありません。

## AIDE ARK GATEの役割

AIDE ARK GATEは、AIが作った候補と実際の送金実行を分ける実行境界を担います。設定された条件や家族の確認がそろっていない場合は処理を保留し、条件に応じてALLOW（許可）／HOLD（保留）／DENY（拒否）で扱うことを想定しています。

**ALLOWは送金の自動実行を意味しません。** 実際の手続きには、本人による確認や金融機関側の手続きが必要です。

## このコンセプトの現在地

本リポジトリは、家庭向けの特殊詐欺対策に関する将来の応用コンセプトを紹介するものです。動画内のメッセージ、人物、口座、金額は架空のイメージです。

詐欺検知、家族への通知、相談用サマリーの生成、警察・消費生活相談窓口への連絡、銀行との連携は実装されていません。動画内で実際の送金や通報は行っていません。本コンセプトは、詐欺被害の防止を保証するものではありません。

## 期待する広がり

同じ考え方を、高額商品の購入、不審な契約、本人や家族の確認が必要なオンライン手続きなど、家庭内の重要な判断に広げることを目指します。
